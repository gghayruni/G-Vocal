# G-Vocal v0.1 — загрузка с новой учётной записи GitHub

1. Скачайте этот ZIP и **распакуйте** его на компьютер. Не загружайте сам ZIP на GitHub как файл проекта.
2. Откройте папку `G-Vocal` из распакованного архива. Все файлы и папки **внутри** неё нужно загрузить в **корень** вашего нового репозитория.
3. В проводнике Windows включите показ скрытых элементов, чтобы видеть `.github`.
4. На GitHub создайте пустой репозиторий `g-vocal` (ветка `main`). Откройте **Добавить файл → Загрузить файлы** (в интерфейсе кнопки могут быть по-английски: **Add file → Upload files**).
5. Перетащите **все элементы внутри** папки `G-Vocal` в окно загрузки. Важно сохранить подпапки `src`, `installer`, `.github/workflows` и `preview`. Нажмите кнопку подтверждения коммита (**Commit changes / Сохранить изменения**).
6. Проверьте в корне репозитория: `CMakeLists.txt`, `src`, `installer`, `.github`. Самих файлов `PluginProcessor.cpp` или `g-vocal.nsi` в корне быть не должно.
7. После проверки перейдите в **Действия / Actions** → **Build G-Vocal Windows VST3 + installer**. Сборка должна стартовать автоматически после загрузки, или запускается через **Run workflow / Запустить рабочий процесс**.
8. Готовый VST3 и Windows-установщик появятся в **Artifacts / Артефакты** только если сборка завершится успешно (зелёная галочка).

Это **исходный код**, а не скомпилированный установщик. Для сборки Windows нужен GitHub Actions; код ещё не проверен успешной сборкой. Не загружайте сюда пароль или ключи доступа GitHub.

При трудностях пришлите скриншот только текущего шага, будем разбирать его по одному действию.
