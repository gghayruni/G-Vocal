# G‑Vocal — как получить VST3 и установщик (Windows)

Это **исходный проект**, а не уже скомпилированный Windows-плагин. Установщик появится **после успешной сборки GitHub Actions**. В текущем окружении авторской сборки нет компилятора MSVC/SDK JUCE, и сборка не была проведена.

## Шаг 1. Загрузить проект

1. Скачайте архив `G-Vocal-source.zip` из переписки и распакуйте его на компьютер.
2. На сайте https://github.com/new создайте **пустой** репозиторий с названием `g-vocal`, без инициализации README. Для личного проекта можно выбрать Private.
3. Если GitHub Desktop удобнее, клонируйте этот репозиторий через программу, скопируйте в папку репозитория **всё содержимое** `G-Vocal` (включая скрытую `.github`), затем выполните Commit и Push.
4. Либо, если установлен Git, откройте PowerShell внутри распакованной папки `G-Vocal` и выполните:

```powershell
git init
git branch -M main
git add -A
git commit -m "Initial G-Vocal project"
git remote add origin https://github.com/ВАШ_ЛОГИН/g-vocal.git
git push -u origin main
```

Замените `ВАШ_ЛОГИН` на логин GitHub. Вход может запросить Git Credential Manager в браузере; пароль от GitHub сюда писать не нужно.

## Шаг 2. Собрать VST

1. Откройте репозиторий → вкладка **Actions**.
2. Если GitHub просит разрешить Actions, разрешите запуск рабочего процесса в **своём репозитории**.
3. Выберите **Build G-Vocal Windows VST3 + installer**, затем **Run workflow**. Он также стартует автоматически при коммите в `main`.
4. После **зелёной галочки** зайдите в выполненный запуск и в **Artifacts** скачайте `G-Vocal-Windows-VST3-and-Setup`.
5. В скачанном архиве должны быть **G-Vocal.vst3** (папка с двоичным плагином) и **G-Vocal-Setup-0.1.0.exe** (установщик).

Если сборка отображается красной, установщик ещё не создан: откройте ошибку сборки и передайте журнал в чат для исправления кода.

## Шаг 3. Установка в Ableton Live 12

1. Запустите `G-Vocal-Setup-0.1.0.exe` на Windows 64-bit с правами администратора.
2. Стандартная папка: `C:\Program Files\Common Files\VST3\G-Vocal.vst3`.
3. Откройте Ableton → Settings/Preferences → Plug-Ins → убедитесь, что VST3 включён → пересканируйте плагины.
4. На вокальную аудиодорожку добавьте **G-Vocal**.
5. Воспроизведите записанный вокал и нажмите **ANALYZE**. За 7 секунд звучания программа измерит RMS/пик и установит приблизительные параметры. При необходимости меняйте все параметры вручную.
6. **ENGINE ON / BYPASS** — кнопка сравнения до/после во время прослушивания. **ON** и **LOCK** доступны для каждого модуля.

## Что реально умеет первая версия

Высокочастотный фильтр и мягкий гейт, трёхполосный EQ, компрессор, простой де-эссер, сатурация, реверберация, задержка, выходная громкость/soft clipping. Пять пресетов: NATURAL, POP, BALLAD, WARM, POWERFUL. Все настройки сохраняются в проект Ableton.

**Важно:** это альфа-версия, не финальный профессиональный продукт и не нейросетевой шумодав. Здесь нет коррекции нот, точной автоматической эквализации по спектру или проверки студийного качества на реальном вокале. Необязательно включать все эффекты; ориентируйтесь на звук.
